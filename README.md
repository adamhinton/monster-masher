# Monster Masher

A full-stack monster catalog app.

This document will be fleshed out as the project progresses.

## Stack

- Frontend: Next.js, TypeScript, Tailwind
- Backend: Django API + Django Admin
- Database: Supabase
- Email delivery: Resend (via Supabase Auth)
- Image generation: Likely Vercel AI SDK, image generation model TBD

## Auth

See `frontend/README.md` for the full auth flow and endpoint reference.
